# Volna — на твоей волне

Устанавливаемое музыкальное PWA-приложение на React и TypeScript. Тёмная лента с синими акцентами, онлайн-каталогом независимой музыки, персональными рекомендациями и сохранением треков на устройстве. Интерфейс адаптирован для телефона и компьютера.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (в облачной среде проверено на Node.js 24).

```sh
cd /workspace/Test-project
npm ci
npm run dev
```

Dev-сервер использует порт `5173`, слушает `0.0.0.0`. Установка зависимостей требует доступа к `registry.npmjs.org`. Для работы приложения внешние API, секреты, база данных и дополнительные сервисы не нужны.

## Установка и офлайн-режим

### Приложение Windows

Готовая сборка **`releases/Volna-1.1.2-Windows-x64.exe`** — самостоятельное приложение Windows x64. Запусти EXE; Node.js и отдельный сервер устанавливать не нужно. Это portable-сборка: приложение распаковывается и открывает собственное окно, установка с правами администратора не требуется. Интерфейс, шрифты, обложки и восемь демотреков находятся внутри. Для внешнего каталога и YouTube нужен интернет. Цифровой подписи у сборки нет.

Приложение поднимает встроенный сервер только на `127.0.0.1:28741`; постоянный адрес сохраняет библиотеку между запусками. Сервер поддерживает перемотку Range, YouTube API и политику CSP. Renderer работает с `sandbox`, `contextIsolation` и без доступа к Node.js. Ссылки открываются в обычном браузере.

```sh
npm run release:windows
```

Для облачной Linux-сборки используй `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci --cache /tmp/volna-npm-cache`, затем `npm run export:html`, `ELECTRON_BUILDER_CACHE=/tmp/volna-builder-cache npx electron-builder --config electron-builder.json --config.electronDownload.cache=/tmp/volna-electron-cache --win portable --x64` и `python3 scripts/package_release.py --windows`. Кэши находятся в доступном для записи `/tmp`; проверка TLS и контрольных сумм загрузок остаётся включённой. EXE в `releases/` хранится обычным файлом Git и имеет размер менее 100 МиБ. В пакет входят русская и английская локали; браузерные зависимости уже встроены в клиентскую сборку. Контрольные суммы готовых файлов находятся в `releases/SHA256SUMS`.

Проверены сборка Windows PE x64, содержимое пакета и встроенный сервер в Chromium: интерфейс с CSP, настоящее воспроизведение/перемотка, импорт CSV и сохранение после перезапуска страницы. Нативный запуск EXE на Windows в этой Linux-среде не проверялся.

### Автономный HTML

Для открытия одним файлом без сервера:

```sh
npm run export:html
```

Готовый `exports/Volna.html` содержит скрипты, стили, шрифты, обложки и весь демокаталог. Скопируй его на компьютер и открой двойным кликом в современном браузере. Интернет и Node.js на компьютере для открытия не нужны. Коллекция хранится локально, если браузер разрешает хранилище для файлов. Установка PWA доступна в серверной версии ниже.

Обычный `index.html` из исходников или из `dist` отдельно открывать нельзя: он загружает остальные файлы приложения через HTTP.

```sh
npm run build
npm run preview -- --port 4173
```

Открой production-версию в браузере через HTTPS или на localhost. В меню профиля или боковой панели выбери «Установить приложение». На iPhone: Safari → «Поделиться» → «На экран Домой».

После первого успешного открытия production-версии service worker сохраняет оболочку, обложки, шрифты и весь демокаталог. Дождись окончания первоначальной загрузки перед отключением сети. Приложение запускается офлайн, воспроизводит треки и поддерживает перемотку. В режиме разработки service worker не регистрируется. Процессы сервера нужно запускать заново в новой облачной задаче; они не входят в снимок среды.

## Возможности

- Открытый каталог Internet Archive: поиск по музыкантам и релизам, жанры, реальные счётчики результатов и загрузка следующих страниц. Все треки мира в приложение не включены: доступность определяют источники и их условия.
- Полные MP3 открытых релизов воспроизводятся непосредственно с Internet Archive. Выбранные записи становятся доступны в локальном поиске, избранном, плейлистах, истории и рекомендациях.
- Скачивание разрешённых записей с прогрессом и отменой; «Скачанное» показывает копии на устройстве и позволяет удалять их. Проверена перезагрузка без сети и воспроизведение с перемоткой из IndexedDB.
- Восемь оригинальных стереотреков по 48 секунд: пауза, переключение, перемотка, громкость, повтор, случайный порядок, полный экран.
- Очередь с добавлением, удалением и очисткой. Системные медиакнопки работают через Media Session при поддержке браузером.
- Поиск по названию, исполнителю, жанру и настроению.
- Рекомендации: лайки формируют предпочтения по жанрам, история добавляет сигнал, недавно прослушанные треки уступают место открытиям.
- Избранное, история, собственные плейлисты и сохранение треков в плейлисты. Коллекция и настройки сохраняются в `localStorage` на текущем устройстве.
- Установка как PWA, офлайн-каталог и мобильная навигация.
- Клавиатура: `Пробел` — воспроизведение/пауза, `Ctrl/⌘ + K` — поиск, `Esc` — закрытие диалога или плеера. Поддерживается уменьшение анимации в системных настройках.

Это рабочая демонстрационная версия с локальным каталогом и профилем. Серверная авторизация, синхронизация между устройствами, коммерческие музыкальные каталоги и подписки не подключены. Композиции созданы программно для этого проекта; имена исполнителей в демокаталоге вымышлены. Подключения к Spotify нет.

## Открытый каталог и скачивание

На главной нажми **«Онлайн-каталог»** или открой **«Каталог»** в боковой панели. Приложение обращается к публичному API Internet Archive, коллекции `netlabels`. Пользовательский API-ключ для него не требуется. Открой релиз, чтобы увидеть полные доступные MP3; «Загрузить следующие релизы» продолжает каталог по страницам, не ограничивая его восемью демотреками. Число результатов берётся из ответа источника.

Это независимые открытые релизы, а не весь каталог коммерческих исполнителей. Можно слушать записи, которые доступны у источника. В меню трека есть ссылка «Источник и условия» с авторством и лицензией. Поиск YouTube для коммерческих релизов остаётся отдельной интеграцией ниже.

Для сохранения на устройстве нажми стрелку вниз рядом с треком. Кнопка доступна, когда метаданные источника содержат распознаваемую лицензию Creative Commons или Public Domain. Для неизвестных условий и закрытых файлов офлайн-сохранение не предлагается. Сохраняются полный аудиофайл и его метаданные в IndexedDB; отметка «Скачано» появляется только после полного чтения и успешной атомарной записи. Отмена и ошибки не создают частичных офлайн-копий.

После скачивания открой **«Скачанное»** (на телефоне: **«Коллекция» → «Скачанное»**). Треки можно воспроизводить и перематывать без сети, а копии удалять кнопкой с галочкой. Сохранения привязаны к текущему браузеру и адресу приложения; перенос одного HTML на другой компьютер не переносит скачанную музыку. Установка PWA даёт постоянный адрес для хранения. Очистка данных браузера удаляет локальные копии. В ограниченном предпросмотре хранилище может быть запрещено — тогда приложение не обещает успешное скачивание.

В автономном HTML онлайн-каталог запрашивается непосредственно браузером. Оболочка и восемь демотреков уже внутри файла, а записи из каталога требуют интернет до их скачивания. YouTube не входит в механизм скачивания: его видео остаются в официальном онлайн-плеере.

Для каталога из облачной среды нужен доступ к `archive.org` и `*.archive.org` (метаданные, обложки, перенаправления аудио). Проверка 15 октября 2026 получила через настоящий API две последовательные партии по 12 записей без повторов; поиск и метаданные вернули `Access-Control-Allow-Origin: *`, а аудио ответило HTTP 206 на Range-запрос, также с CORS `*`. Проверка сохранила TLS и маршрутизацию через прокси среды. Прямой живой запрос из системного Chromium остановился на `ERR_CERT_AUTHORITY_INVALID` для сертификата прокси; проверка сертификатов не отключалась. Поэтому автоматизированные браузерные проверки используют подставные ответы провайдера и настоящий MP3. Офлайн-проверка сохраняет реальный Blob, перезагружает приложение без сети, воспроизводит его с локального `blob:` URL и проверяет удаление из IndexedDB.

## Моя волна

При открытии раздела или нажатии «Слушать мою волну» приложение автоматически ищет полные записи в Internet Archive. Настроение задаёт направление поиска, а лайки и история помогают выбрать жанр. Открывать альбомы в каталоге вручную для этого не нужно. Новая партия содержит до 12 ранее не добавленных треков, максимум два из одного релиза. Обработанные релизы и позиции страниц сохраняются на устройстве, чтобы продолжать открытия после перезагрузки.

«Обновить волну» загружает следующую партию и ставит её в начало рекомендаций. Текущая композиция продолжает играть; новые записи попадают следующими в очередь. При активной волне и трёх оставшихся открытиях очередь пополняется автоматически. Выбор другого плейлиста или очистка очереди выключают это пополнение. Смена настроения отменяет устаревший запрос и обновляет рекомендации.

При недоступном источнике приложение показывает ошибку и сохраняет доступ к ранее добавленной музыке. «Обновить волну» повторяет запрос. Без сети новые записи не появляются; доступны встроенные и скачанные треки. Волна использует открытый каталог Internet Archive; поиск и официальный плеер YouTube остаются отдельным разделом.

## Перенос из Яндекс Музыки

Открой **«Перенести библиотеку»** в боковой панели; на телефоне — **«Коллекция» → «Перенести библиотеку»**. Выбери CSV или JSON, проверь найденные треки, выбери сохранение плейлистов/избранного и нажми «Перенести». Файл читается локально и не отправляется на сервер. Поддерживаются файлы до 10 МБ и 10 000 записей.

CSV распознаёт русские и английские заголовки: «Название»/title/Track name, «Исполнитель»/artist/Artist name, «Альбом»/album, «Плейлист»/playlist, «Избранное»/liked. Разделители — запятая, точка с запятой, табуляция; поддерживаются BOM, кавычки и переносы внутри полей. JSON принимает tracks, playlists, likedTracks, обёртки result/library и вложенные объекты track, artists, albums из экспортов API. Файл только с ID не содержит названий и не импортируется.

Повторные записи объединяются с сохранением всех плейлистов и отметок «Любимое». Повторный импорт дополняет существующую коллекцию без копий. При ошибке записи в хранилище предыдущие значения восстанавливаются; ложного сообщения об успешном сохранении нет.

Переносятся метаданные и списки. Для импортированного трека нажми значок поиска: серверная версия покажет найденные записи YouTube для выбора и официального плеера, автономный HTML откроет поиск YouTube в браузере. Сохраняется ссылка на оригинал в Яндекс Музыке. Аудиофайлы, подписка и разрешение на офлайн-прослушивание Яндекса не переносятся. Импортированные метаданные не выдаются за готовые аудиопотоки.

## YouTube

Общая строка поиска по умолчанию ищет на YouTube после короткой паузы ввода. Результаты показаны списком: обложка, название, канал и кнопка воспроизведения. При смене запроса предыдущая загрузка отменяется. Вкладка «В библиотеке» ищет среди добавленных треков; кнопка «Онлайн-каталог» открывает Internet Archive.

YouTube использует общий нижний плеер: текущая запись, пауза, перемотка, громкость, следующая/предыдущая запись, повтор и очередь. Официальное видео закреплено в нижней панели, отдельной всплывающей панели нет. Сердечко и плюс доступны прямо в результатах и нижнем плеере. Сохраняются названия, источники, избранное и плейлисты; записи открываются в том же плеере после перезапуска. Новые страницы текущего поиска пополняют его активную очередь. Скачивание аудио YouTube не реализовано.

Ошибки официального плеера показываются рядом с текущей записью: удалённое видео, запрет встраивания (101/150), ошибка идентификации источника (153), блокировка автозапуска или недоступность API. Во время ошибки старый локальный трек не выдаётся за играющий. Можно выбрать другую запись или открыть оригинал на YouTube. Ограничения автора и региона не обходятся.

В «Моей волне» при воспроизведении движутся синие частицы и светящиеся орбиты. Декоративная Canvas-анимация работает с ограниченной частотой кадров, останавливается на паузе и учитывает `prefers-reduced-motion`; она не анализирует аудиопоток.

Раздел **YouTube** ищет публичные видео без пользовательского API-ключа через [YouTube.js от LuanRT](https://github.com/LuanRT/YouTube.js), MIT, npm-пакет `youtubei.js` версии `18.1.0`. Поддерживаются результаты, обложки, следующие страницы и открытие по ссылке. Поиск использует неофициальный публичный интерфейс YouTube и может перестать работать при изменениях у источника или ограничениях доступа. Тогда доступна ссылка «Открыть поиск на YouTube».

Запусти серверную версию командой `npm run dev` или `npm run preview` после сборки. Пользовательский ключ, аккаунт YouTube и cookies для поиска не нужны. Сервер запрашивает только публичные метаданные; загрузка скриптов извлечения аудио и извлечение аудиопотоков отключены. Клиент подключает официальный YouTube IFrame API с `www.youtube.com/iframe_api` для управления видимым плеером `youtube-nocookie.com`. Передаются реальный origin и referrer приложения. Локальная музыка останавливается при запуске YouTube. Доступность встраивания и региональные ограничения определяет YouTube.

При желании можно использовать официальный **YouTube Data API v3**: создай собственный ключ в [Google Cloud](https://console.cloud.google.com/apis/library/youtube.googleapis.com) и сохрани секрет `YOUTUBE_API_KEY` в настройках среды. При наличии ключа сервер выбирает официальный API и его квоты. Ограничь серверный ключ этим API; он остаётся на сервере и не включается в клиент, HTML и ошибки. Использовать чужой ключ из исходников не требуется.

Разреши `www.youtube.com` для публичного поиска; для плеера — `www.youtube-nocookie.com`, `www.youtube.com`, `i.ytimg.com`, `s.ytimg.com`, `*.googlevideo.com`. Для режима официального API дополнительно нужен `www.googleapis.com`. В облачной среде примени сетевые настройки и перезапусти сервер. `/api/youtube/status` показывает `{configured: true, mode: "public"}` либо `mode: "official"`; это режим настройки, а не проверка доступности провайдера.

API реализован middleware в `server/youtube.mjs` для Vite dev и preview. Публичный клиент подключается в `server/public-youtube.mjs`, все сетевые запросы сохраняют проверку TLS и маршрутизацию через прокси среды. При размещении только статической папки `dist` для поиска нужен этот серверный обработчик. Одинаковые запросы кэшируются на 15 минут; токены страниц ограничены сроком и привязаны к запросу.

В автономном HTML кнопка поиска и ссылки открывают YouTube в отдельной вкладке: YouTube требует веб-контекст для надёжной работы встраиваемого плеера. Для результатов внутри приложения используй серверную версию. YouTube требует интернет и не входит в офлайн-каталог.

Интеграционные тесты используют настоящий клиент YouTube.js и ответы формата провайдера, проверяют поиск без пользовательского ключа, следующую страницу, кэш, истечение токенов и обработку ошибок. Браузерные проверки используют подставные ответы. Повторная проверка 15 октября 2026 года: API поиска вернул HTTP 502, прямое соединение с `www.youtube.com` блокируется прокси с CONNECT HTTP 403. Живой поиск и воспроизведение YouTube из этой облачной среды не подтверждены. Сетевые требования сохранены в черновике настроек; сохранение черновика не применяет их к запущенной среде.

## Проверки

```sh
npm run build
npm test
npm run test:e2e
```

Проверка масштаба в Playwright загружает 120 разных треков десятью партиями, проходит три страницы каталога, проверяет отсутствие повторов, поиск по всем 120 записям, очередь из 120 треков, настоящее воспроизведение и сохранение после перезагрузки. Внешний источник здесь подставной. Unit-проверка дополнительно ранжирует 128 записей по вкусу и настроению.

Для отдельной проверки настоящего источника без подставных ответов:

```sh
npm run test:wave:live
```

Она получает минимум 120 разных записей из живого Internet Archive через тот же загрузчик волны, затем проверяет настоящий MP3: 64 КиБ, HTTP 206, Range и CORS. Нужен сетевой доступ к источнику. Скрипт сохраняет проверку TLS и прокси среды; по умолчанию он не входит в воспроизводимый набор тестов.

Unit-тесты проверяют адаптацию рекомендаций к вкусу, фильтрацию по настроению, поиск, новые партии волны без повторов и переход между страницами. Playwright проверяет настоящее воспроизведение и перемотку, очередь, поиск, сохранение избранного, создание и наполнение плейлистов, мобильный экран, перезагрузку и воспроизведение без сети. Проверки волны покрывают автоматические открытия, обновление без прерывания текущей музыки, пополнение очереди, сохранённую позицию поиска, смену настроения и восстановление после ошибки источника. Ответы внешнего каталога в этих тестах подставные.

Playwright использует системный Chromium из `/usr/bin/chromium`. Для другого расположения задай `CHROMIUM_PATH`. E2E-тесты запускают production-сервер на порту `4173`; сначала выполни сборку. Нужна новая сборка после изменения приложения, поскольку офлайн-кэш содержит файлы из `dist`.

```sh
npm run format
```

## Структура

- `src/App.tsx` — экраны, коллекция, очередь и управление плеером.
- `src/catalog.ts` — музыкальный каталог и подборки.
- `src/recommendations.ts` — локальное ранжирование и поиск.
- `src/wave.ts`, `src/useWave.ts` — поиск новых треков для волны, отмена запросов, сохранённые позиции и партии рекомендаций.
- `src/storage.ts` — сохранение состояния устройства.
- `src/LibraryImport.tsx`, `src/libraryImport.ts` — импорт CSV/JSON, предпросмотр и объединение коллекций.
- `src/OpenLibrary.tsx`, `src/openCatalog.ts` — постраничный каталог Internet Archive, источники и разрешения на скачивание.
- `src/offline.ts` — сохранение полных аудиофайлов в IndexedDB, прогресс, отмена и удаление.
- `src/YouTubeLibrary.tsx`, `src/youtube.ts` — поиск, ссылки и официальный плеер YouTube.
- `server/youtube.mjs`, `server/public-youtube.mjs` — публичный поиск через YouTube.js и дополнительный режим официального Data API, без передачи ключей клиенту.
- `desktop/main.mjs`, `server/app-server.mjs`, `electron-builder.json` — Windows-окно, встроенный сервер и portable EXE.
- `src/styles.css` — адаптивная визуальная система и оригинальные обложки.
- `public/audio` — готовый демокаталог, без внешних запросов при воспроизведении.
- `scripts/build-sw.mjs` — версионированный офлайн-кэш, включая обработку Range-запросов для аудио.
- `scripts/export-portable.mjs` — автономный HTML с встроенными ресурсами, без внешних запросов для локального каталога.
- `scripts/package_release.py` — упаковка готового HTML и инструкции в `releases/Volna.zip`. Команда `npm run release` пересобирает HTML и обновляет готовые файлы.
- `scripts/generate_audio.py` — воспроизводимый синтез композиций; только для повторного создания аудио нужны Python, NumPy и FFmpeg. Обычный запуск приложения их не требует.
