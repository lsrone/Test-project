# Готовые файлы Volna

- `Volna-1.2.1-Windows-x64.exe` — самостоятельное Windows-приложение. Запусти EXE, установка Node.js не нужна. Сборка без цифровой подписи; нативный запуск на Windows в облачной Linux-среде не проверен.

- `Volna.html` — автономное приложение, все файлы и восемь демотреков встроены (около 9 МБ).
- `Volna.zip` — тот же HTML и краткая инструкция в архиве (около 6,6 МБ).
- `SHA256SUMS` — контрольные суммы готовых файлов.

Распакуй ZIP и открой `Volna.html` в браузере. Сервер и установка зависимостей для этой версии не требуются. Для установки PWA и поиска YouTube используй серверную версию, описанную в основном README.

В HTML поиск YouTube открывается на сайте YouTube в новой вкладке. В серверной версии результаты загружаются прямо в приложение через открытый клиент [YouTube.js](https://github.com/LuanRT/YouTube.js); пользовательский API-ключ для этого не нужен.

Поиск в верхней панели по умолчанию использует YouTube и показывает результаты списком. Для своих треков переключись на «В библиотеке». Плашка профиля и колокольчик убраны.

В 1.2.1 исправлены ложные запреты при отсутствующем поле ответа YouTube и лишняя обязательная загрузка скрипта проигрывателя. Windows-запросы учитывают системную сеть и прокси через Electron. По кнопке «Копировать диагностику» можно передать безопасный код и этап ошибки. Явные ограничения источника и проверки входа не обходятся; гарантировать работу всех записей не можем.

В версии 1.2.0 видео удалено полностью: YouTube использует только общий аудиоплеер внизу. Если запись ограничена, приложение ищет совпадающую доступную запись и явно показывает замену; ограничения автора и региона не обходятся. «Алекс» убран, новые добавления в избранное и плейлисты появляются сверху. Старые списки мигрируют при первом запуске с сохранением состава. Системное меню Electron больше не перехватывает Alt при смене раскладки. Нативная проверка Windows в облаке недоступна.

Рекомендации учитывают выбранные или сохранённые в поиске треки, избранное, плейлисты, прослушивания и быстрые пропуски. Для выбранных YouTube-треков волна ищет похожие записи; при отсутствии предпочтений использует Internet Archive. Анимированные частицы учитывают настройку уменьшения анимации.

Пройдены 45 unit/integration и 27 браузерных сценариев, включая 120+ треков. Аудио без видео дополнительно проверено через встроенный сервер и CSP с настоящим AAC/MP4; ответы источника подставные. Живой YouTube в этой среде заблокирован прокси (CONNECT 403), его воспроизведение здесь не подтверждено.

В приложении есть онлайн-каталог Internet Archive с поиском и следующими страницами релизов. Полные записи с подходящими условиями можно сохранить стрелкой вниз и слушать из раздела «Скачанное» без сети. Копии хранятся в браузере; они не включаются в этот ZIP. Для поиска и первоначального скачивания нужен доступ к источнику. Восемь встроенных демотреков доступны без сети сразу.

«Моя волна» автоматически находит новые записи с учётом личных предпочтений и настроения и пополняет очередь. Кнопка «Обновить волну» загружает следующую партию. Для новых открытий нужен интернет и доступ к выбранному источнику; при ошибке источника приложение показывает причину.

«Перенести библиотеку» импортирует CSV/JSON из Яндекс Музыки: треки, плейлисты и избранное. Для импортированных записей доступен поиск на YouTube. Аудиофайлы и подписка Яндекса не переносятся.

Эти файлы — готовая сборка, включённая в проект. Промежуточная папка `exports/` остаётся исключённой из Git.

Если интерфейс чата показывает «Не удалось загрузить этот файл» ещё до открытия приложения, это ошибка передачи или предпросмотра файла. Она не является проверкой запуска HTML. В таком случае скачай готовую сборку через репозиторий после её отправки в GitHub.
