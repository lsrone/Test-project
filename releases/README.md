# Готовые файлы Volna 1.6.0

- `Volna-1.6.0-Windows-x64.exe` — portable Windows x64. Полностью закрой старую Volna перед запуском.
- `Volna.html`, `Volna.zip` — автономный HTML со встроенными демотреками; `SHA256SUMS` — контрольные суммы.

Импорт поддерживает TXT/TSV, CSV и JSON. Для TXT — один трек на строку: `Polar Echo - First Light`. Проверь предпросмотр; можно поменять порядок исполнителя и названия. Поддерживаются UTF-8, UTF-16 и Windows-1251. Файл «Мне нравится» включает сохранение записей в избранное. Личный список пользователя в EXE и репозиторий не встроен.

Плеер YouTube из 1.1.2 возвращён и объединён с текущей библиотекой: видимое видео находится в нижней панели, музыка управляется общими кнопками Volna. Сохранены TXT-импорт, поиск списком, рекомендации, частицы, новые лайки сверху, плейлисты и локальное аудио. Старые записи с YouTube ID воспроизводятся без повторного добавления. Для импортированной записи без ID нажатие запускает поиск точного совпадения исполнителя и названия. При отсутствии точного совпадения выбирай запись вручную через подбор и цепочку. Исходный ID, лайк и плейлисты сохраняются.

Ограничения автора, региона и удалённые записи могут мешать воспроизведению. Работа всех треков не гарантируется. «Другая запись» позволяет выбрать другую версию, сохранив исходную запись в коллекции. Автоматического открытия браузера нет. Вкладка «Аудиокаталог» и «Моя волна» используют полные MP3 Internet Archive; разрешённые записи можно скачать для офлайна.

Через меню трека можно прикрепить собственный MP3/M4A/OGG/WAV/FLAC до 250 МБ. Файл хранится на устройстве и имеет приоритет над YouTube; офлайн, замена и удаление сохраняются. Личный список пользователя не включён в сборку.

Проверки внешнего YouTube используют тестовый источник с настоящим MP3 для проверки управления и хранения, включая production CSP; они не подтверждают доступность живого YouTube. В облаке загрузка YouTube SDK получает CONNECT 403. Нативный Windows-запуск не проверен.

Пройдены 44 unit/integration и 34 end-to-end сценария; 41 файл внутри пакета совпадает с проверенными файлами приложения.
