# Готовые файлы Volna 1.4.0

- `Volna-1.4.0-Windows-x64.exe` — portable Windows x64. Полностью закрой старую Volna перед запуском; Node.js не нужен.
- `Volna.html` — автономное приложение с восемью демотреками; `Volna.zip` — тот же HTML с инструкцией.
- `SHA256SUMS` — контрольные суммы.

По умолчанию поиск идёт по публичной выдаче YouTube, с загрузкой следующих страниц. Записи сохраняются в избранное/плейлисты и **открываются на YouTube в обычном браузере**. Видео внутри приложения не добавлено. При недоступности выдачи есть повтор и прямая ссылка на поиск; можно вставить ссылку записи. Полнота индекса и доступность каждой композиции не гарантируются.

Для импортированного трека Яндекса нажми лупу, выбери результат YouTube и свяжи его кнопкой цепочки. Сохраняются исходный трек, лайк и плейлисты. Аудиофайлы и подписка Яндекса не переносятся.

Вкладка «Аудиокаталог» и «Моя волна» используют полные MP3 Internet Archive / netlabels. Только эти и встроенные записи играют в нижнем аудиоплеере. Стрелка скачивания сохраняет разрешённые CC/Public Domain MP3 в IndexedDB для офлайн-прослушивания. Ссылки YouTube не скачиваются и не добавляются в аудиоочередь.

Проверено 38 unit/integration и 29 сценариев интерфейса, включая 120 тестовых результатов YouTube и привязку импорта без потери данных. Реальное аудио Archive, перемотка и переключение проверены в Linux Electron. В облачной сети YouTube отклонил подключение с HTTP 403, поэтому живая выдача YouTube здесь не подтверждена. Нативный Windows-запуск не проверен.

В автономном HTML поиск YouTube открывается на сайте. Для выдачи внутри приложения используй EXE или запущенную серверную версию. Для MP3-каталога нужен интернет; демотреки встроены.
