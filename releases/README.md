# Готовые файлы Volna

- `Volna.html` — автономное приложение, все файлы и восемь демотреков встроены (около 9 МБ).
- `Volna.zip` — тот же HTML и краткая инструкция в архиве (около 6,6 МБ).

Распакуй ZIP и открой `Volna.html` в браузере. Сервер и установка зависимостей для этой версии не требуются. Для установки PWA и поиска YouTube используй серверную версию, описанную в основном README.

В HTML поиск YouTube открывается на сайте YouTube в новой вкладке. В серверной версии результаты загружаются прямо в приложение через открытый клиент [YouTube.js](https://github.com/LuanRT/YouTube.js); пользовательский API-ключ для этого не нужен.

В приложении есть онлайн-каталог Internet Archive с поиском и следующими страницами релизов. Полные записи с подходящими условиями можно сохранить стрелкой вниз и слушать из раздела «Скачанное» без сети. Копии хранятся в браузере; они не включаются в этот ZIP. Для поиска и первоначального скачивания нужен доступ к источнику. Восемь встроенных демотреков доступны без сети сразу.

«Моя волна» автоматически находит новые записи в открытом каталоге, учитывает настроение и пополняет очередь. Кнопка «Обновить волну» загружает следующую партию. Для новых открытий нужен интернет и доступ к Internet Archive; при ошибке источника приложение показывает причину.

Эти файлы — готовая сборка, включённая в проект. Промежуточная папка `exports/` остаётся исключённой из Git.

Если интерфейс чата показывает «Не удалось загрузить этот файл» ещё до открытия приложения, это ошибка передачи или предпросмотра файла. Она не является проверкой запуска HTML. В таком случае скачай готовую сборку через репозиторий после её отправки в GitHub.
