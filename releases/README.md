# Готовые файлы Volna 1.5.0

- `Volna-1.5.0-Windows-x64.exe` — portable Windows x64. Полностью закрой старую Volna перед запуском.
- `Volna.html`, `Volna.zip` — автономный HTML со встроенными демотреками; `SHA256SUMS` — контрольные суммы.

Импорт поддерживает TXT/TSV, CSV и JSON. Для TXT — один трек на строку: `Polar Echo - First Light`. Проверь предпросмотр; можно поменять порядок исполнителя и названия. Поддерживаются UTF-8, UTF-16 и Windows-1251. Файл «Мне нравится» включает сохранение записей в избранное. Личный список пользователя в EXE и репозиторий не встроен.

Автоматический переход на YouTube отключён. Кнопка на обложке записи без аудио предлагает выбрать свой файл MP3/M4A/OGG/WAV/FLAC до 250 МБ. Он сохраняется на устройстве и воспроизводится в нижнем аудиоплеере, в том числе без сети. Лайк, ID и плейлисты сохраняются; можно заменить или удалить файл. Сам TXT содержит только названия и исполнителей, аудио YouTube без видео не восстановлено.

Поиск метаданных YouTube, страницы, избранное и связывание импорта Яндекса сохранены. Источник доступен в браузере только по явному действию. Вкладка «Аудиокаталог» и «Моя волна» используют полные MP3 Internet Archive; разрешённые записи можно скачать для офлайна.

Проверены 43 unit/integration и 32 сценария интерфейса. Дополнительно в Linux Electron проверен личный TXT из 509 записей и лайков без внешней передачи, сохранение коллекции и механизм локального аудио на оригинальном демо-MP3. Нативный Windows-запуск не проверялся.
