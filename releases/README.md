# Готовые файлы Volna 1.3.0

- `Volna-1.3.0-Windows-x64.exe` — portable-приложение Windows x64. Полностью закрой старую Volna перед запуском. Установка Node.js не нужна; цифровой подписи нет.
- `Volna.html` — автономное приложение со всеми ресурсами и восемью демотреками, около 9 МБ.
- `Volna.zip` — тот же HTML с инструкцией.
- `SHA256SUMS` — контрольные суммы.

Поиск и «Моя волна» используют **Internet Archive / netlabels** с полными MP3. Видео и YouTube API удалены; вход и API-ключи не нужны. Это каталог независимой музыки: популярные коммерческие треки могут отсутствовать.

Поиск показывает треки списком и загружает следующие партии. Музыка управляется из нижней панели. Новые лайки и добавления в плейлисты появляются сверху. Рекомендации учитывают выбранные в поиске записи и стили запроса, лайки, плейлисты, прослушивания и пропуски; в волне движутся частицы.

Старые YouTube- и Яндекс-записи остаются в библиотеке как названия и ссылки с отметкой «Нет аудио». Значок поиска ищет их в новом источнике; совпадения не гарантированы. Эти записи не попадают в очередь аудио.

Стрелка скачивания доступна для MP3 с подтверждёнными CC/Public Domain условиями. Полная копия сохраняется на устройстве в IndexedDB, раздел «Скачанное» работает без сети. Перенос HTML не переносит скачанные файлы. Восемь демотреков встроены сразу. CSV/JSON-импорт из Яндекс Музыки переносит только списки и метаданные.

Проверены воспроизводимые сценарии приложения, 120 треков настоящего каталога, настоящий MP3 и фактическое браузерное воспроизведение через встроенный сервер/CSP с паузой, перемоткой и сохранением избранного. Нативный запуск EXE в Windows в облачной Linux-среде недоступен.

Для HTML распакуй ZIP и открой `Volna.html` в современном браузере. Онлайн-каталог требует интернет и CORS источника. Ошибка передачи файла в чате не является проверкой приложения: скачай готовую сборку по ссылке GitHub.
